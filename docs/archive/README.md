# Legacy documentation archive

These documents record earlier Pi-Tai product and implementation designs. They are retained for reference, but they are not normative for the refreshed subsystem designs under `docs/`.

Notable legacy sources:

- `legacy/PRD.md` and `legacy/IMPLEMENTATION_PLAN.md` — earlier whole-product direction.
- `legacy/SUBAGENTS.md` — implemented declarative-subagent behavior before the concurrency redesign.
- `legacy/WORKSPACE_CAPABILITIES_PLAN.md` — superseded JJ/Git capability and relocation design history.
- `legacy/HOST_ARCHITECTURE.md`, `legacy/ACP_SCOPE.md`, and related plans — prior Host and ACP design.
- `legacy/adr/` and `legacy/proofs/` — historical decisions and implementation proofs.

When an archived document conflicts with an active subsystem document, the active document controls.
